# 交付前自查清单 · 学术 PPT 生成与编辑

## 契约

- [ ] `result.json` 含 `case_id` 与 `output_contract` 声明的全部字段
- [ ] `status` 为真实运行状态，不是占位值
- [ ] `sources` 非空，每条可定位（路径 + p.N/sec.N/sent.K 级锚点）
- [ ] `uncertainty` 列出未决项，或明确写 none
- [ ] `change_log` 至少一条，记录实际做过的动作

## 内容

- [ ] 完成内容取舍与页序规划，明确每页承担的叙事角色（背景/方法/结果/结论），不按论文目录逐节搬运
- [ ] 支持按指令压缩、扩写、换受众（导师/评审/同行）、换语言地改写页面内容，并保持术语、符号与论文一致
- [ ] 插入图表：还原论文图表或数据表，处理图注、编号、单位与引用，并明确区分可重绘图表与只能引用原图的图表
- [ ] 关键数字逐字回抄并核对，保留原有精度，不按印象取整；图注与图上标注一致
- [ ] 多轮修改保持版本可比对：记录每轮改了什么、为什么改、改坏后如何回退；改一页不得改坏母版与后续页
- [ ] 在模板字体、配色、页脚规范内成稿，处理槽位不足、长标题、多图并排与页数超限
- [ ] 导出 PDF 与逐页 PNG 校验字体未替换、图片未裁、版式未塌，并输出逐页 diff
- [ ] result.json 写齐页结构与叙事角色、页级证据映射、渲染与版本记录

## 红线

- [ ] 未违反：不得整段贴论文摘要或 Results 塞满页面；不得放占位图或凭空生成的曲线当实验数据
- [ ] 未违反：不得改坏母版与后续页；批量改动必须可回退并留版本记录
- [ ] 未违反：不得覆盖模板字体、配色、页脚风格
- [ ] 未违反：必须交付可打开可编辑的 pptx，而不只是 PDF 或图片
- [ ] 未违反：不得编造运行结果、benchmark 分数或未执行的导出动作

## 可核验指标

- [ ] 叙事角色覆盖率 = 明确标注角色的页数 / 总页数，目标 100%
- [ ] 图表一致率 = 与论文数据一致的插入图表数 / 插入图表总数，目标 100%
- [ ] 迭代可回退率 = 有可用回退点的轮次数 / 总轮次数 = 100%
- [ ] 越界改动条数 = 0（未改母版、主题与其他页面的改动数）
- [ ] 溢出或塌版页数 = 0 且导出后字体被替换页数 = 0
- [ ] 超出固定页数上限的页数 = 0
