# 质量检查表（对齐 5 个评分维度）

## 1. 实际效果（40 分）

| 检查项 | 合格线 | 谁来查 |
|-|-|-|
| 两种模式可用 | `generate` 从论文/大纲成稿；`edit` 按声明式指令改指定页 | 两种模式各跑一遍 |
| 页面正确性 | 数字、单位、图注、引用编号与原文一致 | `deck_build check --corpus`（硬错误） |
| 页结构完整 | 有标题页、问题/方法/结果/结论，页型合法、序号连续 | `deck_build check` |
| 讲稿齐备 | 每页 `notes.say` ≥20 字，讲过渡与追问点 | `deck_build check` |
| 编辑可追溯 | 每条改动有页号、字段、前后值、原因 | `diff.md` / `diff.json` |
| 迭代可回退 | 保留 `work/deck_spec.json`；重跑 edit 可复现同一版 | 重复运行一致性 |
| 演示件可打开 | pptx 由 python-pptx 实际写出；无则如实 partial | `render_log.exports` |

## 2. 使用增益（25 分）

- 基础 Agent 常见失败：改一页顺手改坏母版/其他页、说不清改了什么、数字从正文抄错。
- 本包把“编辑”收敛为声明式 op + 前后值 diff，返工从“整册重做”变成“按 diff 定点复核”。
- 效率：`deck_build edit` 一次生成新版稿、讲稿、diff、pptx，无需手工同步多个文件。
- 可验证：同一 `base + edits` 重复运行输出一致（无随机、无网络）。

## 3. 创新增益（15 分）

- **页级 diff 契约**：`{slide, op, field, before, after, reason}` 同时服务于人读（`diff.md`）
  和机器校验（`result.json.diff`），可直接接入版本对比。
- **生成/编辑同构**：两种模式共用同一 spec 与审计器，编辑后的稿仍过同一套质量门。
- **漂移检测**：未在 edits 中声明却被改动的字段会被标 `drift`（仅在页序不变时启用）。

## 4. 可靠体验（10 分）

| 情况 | 处置 |
|-|-|
| 编辑页号不存在 | 记入“未应用”，`uncertainty` 说明，不静默跳过 |
| 未知 op | 同样记入“未应用”，提示先翻译成声明式操作 |
| 编辑无实际变化 | `status=partial`，`limits` 写“编辑未产生实际变化” |
| 论文缺图/位图 | 引用原文编号与图注，不重绘假数据 |
| 无 python-pptx | `deck.md` + 讲稿 + diff 照常交付，`partial`，不报错 |
| 页数/密度超限 | 一次性列全硬错误，按清单拆页或压缩 |

## 5. 生态贡献（10 分）

- `SKILL.md` 给出触发/输入别名/两种模式流程/契约/自查/降级。
- `references/` 提供契约、检查表、合成示例；`edits.json` 格式可被其他幻灯片工具复用。
- `scripts/spec_io.py` 的规格规范化、Marp 渲染、可选 pptx 构建可独立复用。
