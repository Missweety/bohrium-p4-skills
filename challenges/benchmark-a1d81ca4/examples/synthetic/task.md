# SYNTHETIC demo task (not an official case)

The material in `materials.md` is fabricated. Read it and build a four-item
source-conditioned reading benchmark:

1. one numeric item (value + unit + locator),
2. one table item (specific row),
3. one absence item (answer must say the result is not reported),
4. one condition item (answer must include the limiting condition).

Every item must carry a gold answer, an evidence quote with a locator and a
0/1/2 rubric. Do not copy an answer into the question.
