# 论证地图与结构问题分类（writing）

本文件是 `SKILL.md` 第 4–6 步的判定依据。原则：**先建图，再判缺陷**。没有图就不要写诊断。

## 1. 论点—论据映射的最小字段

```json
{"claim_id":"C07","claim":"该涂层在 3.5% NaCl 中将腐蚀速率降低 38%",
 "section":"3.2","paragraph_id":"P014","sentence_index":2,
 "evidence":[{"ref":"Fig.2b","kind":"figure","locator":"§3.2 ¶2"},
             {"ref":"P011","kind":"text","locator":"§3.1 ¶4"}],
 "reasoning":"以极化曲线拟合的 icorr 差值计算，未做长期浸泡",
 "serves":"结论 K2：涂层在盐雾环境下有效",
 "claim_type":"quantitative","strength":"medium"}
```

`claim_type`：`quantitative`（数值）/ `causal`（因果）/ `comparative`（对比）/ `general`（一般陈述）。
`strength`：`strong`（有对照+统计检验+条件完整）/ `medium`（有数据但缺对照或条件不全）/
`weak`（仅趋势、单样本、仅引用他人）/ `none`（无证据）。

## 2. 论证链断点（claim → evidence → reasoning → conclusion）

| 断点类型 | 可复核信号 | 典型原文形态 | 对应动作 |
|-|-|-|-|
| `claim_without_evidence` | 论断句所在段与相邻段无图/表/引用/数据 | "This demonstrates the mechanism."（本段只讲现象） | ADD_EVIDENCE 或 NARROW |
| `evidence_too_weak` | 单样本、无对照、无重复、无统计量，却用因果/普适措辞 | n=1 的试点 + "proves" | NARROW + FLAG_GAP |
| `level_mismatch` | 证据层级 < 主张层级：相关→因果、体外→体内、单一材料→普适 | 细胞实验支持"临床有效" | NARROW（限定范围） |
| `cross_section_jump` | 结果支持的命题 ≠ 讨论/结论讨论的命题 | 结果只有 A，讨论转谈 B 的意义 | FLAG_GAP + REWRITE_TRANSITION |
| `circular` | 结论中的前提回到引言假设，中间无独立证据 | "因为有效，所以有效" | ADD_EVIDENCE 或删除该结论 |
| `rq_unanswered` | RQ 的子问题在结果/结论中无对应段落 | 引言提 3 问，结果只答 1 问 | FLAG_GAP（写明缺哪一问） |
| `conclusion_overreach` | 结论出现"所有/普遍/首次/证明/完全"且数据范围不足 | 单一 pH 下的结果 → "广泛适用" | NARROW |

判定顺序：**先找证据，再评强度，最后看措辞**。措辞只是症状，不能反过来当证据。

## 3. 研究问题与贡献对齐

检查三处是否同一件事：

1. 引言末段的研究问题 / 目标句（RQ）；
2. 方法段实际做了什么（对象、变量、条件、样本量）；
3. 结论段声称完成了什么（贡献主张）。

| 失配形态 | 例子 | 写法 |
|-|-|-|
| RQ 宽、做法窄 | 问"机理"，只测了宏观性能 | `NARROW`：把 RQ 或贡献限定为"性能表征"，或 `FLAG_GAP` 补机理证据 |
| RQ 窄、贡献吹大 | 只做一种材料，声称"普适策略" | `NARROW` 贡献表述 |
| RQ 消失 | 引言提出问题，后文不再回应 | `REWRITE_TRANSITION` + 在结论补回应（不新增事实） |
| 贡献与结果不符 | 贡献写"首次提出"，结果与他人方法相同 | `NARROW` 去掉"首次"，或补对比证据 |

反例：只写"研究问题不够清晰"——没有指出 RQ 句在哪、与哪段方法不匹配，属无效诊断。

## 4. 章节权重与叙事顺序

权重用字符占比（`structure_probe.py` 的 `weights`），只作线索，需结合体裁：

| 观察 | 可能问题 | 但要先排除 |
|-|-|-|
| 单节 > 45% | 该节挤占论证空间 | 综述型/方法学论文的正常结构 |
| 结果 + 讨论 < 25% | 论证主体过薄 | 短通讯、letter 体裁 |
| 引言 > 35% | 背景铺陈过长，问题出现太晚 | 新领域需要较多铺垫 |
| 方法 > 40% | 细节淹没问题 | 方法学论文 |

顺序检查（不是套模板，而是查依赖）：
- 结论依赖的概念/指标，是否在首次使用前定义；
- 结果依赖的方法细节，是否在结果前给出（或明确指向补充材料）；
- 讨论引用的对照研究，是否在引言/相关工作出现过（否则是突兀引入）；
- 局限性是否出现在结论之前，而不是藏在补充材料。

## 5. 段落关系

| 问题 | 信号 | 动作 |
|-|-|-|
| 一段多主题 | 段落中出现两个以上主题句候选，后句与前句无指代/逻辑连接 | SPLIT，给出拆分点（第 k 句） |
| 多段一主题 | 连续 2–3 段围绕同一论点，无递进 | MERGE，指明保留哪段主题句 |
| 缺过渡 | 段首直接换对象，无回指；`this/it/such` 指代不明 | REWRITE_TRANSITION，给出衔接句要表达的关系（因果/对照/递进） |
| 主题句与内容不符 | 首句承诺 A，段内讲 B | 改主题句或移动段落（二选一，写清理由） |

反例：以"段落太长"为诊断——长度本身不是结构问题，除非造成多主题或指代歧义。

## 6. 重复内容

三类，处理方式不同：

1. **同义重复**（同一句意思换词出现）：合并，保留信息更全的一处；
2. **跨节重复**（方法在方法段和结果段各描述一次）：结果段改为回指（"按 §2.3 流程"），删重复描述；
3. **结构性重复**（引言与讨论重复综述同一文献）：讨论改为"与 X 的差异在于…"，保留对比信息。

禁止：把两段都有独立数据的段落判为重复；删除唯一给出实验条件的段落。
`repetition_probe.py` 写回的 `repetition_pairs` 只是候选（Jaccard/SequenceMatcher），必须回读确认语义是否重复。

## 7. 结论边界

逐条核对结论句与数据范围：

| 检查项 | 不通过的表现 | 收窄写法（示例） |
|-|-|-|
| 因果 vs 相关 | 观测数据用 cause / 导致 / 决定 | "与…相关""在…条件下观察到" |
| 样本范围 | n=3 却说"普遍" | "在本研究的 3 组样品中" |
| 条件范围 | 只测 pH 6，结论不写条件 | "在 pH 6.0、25 °C 条件下" |
| 时间尺度 | 72 h 实验推长期稳定性 | "短期（72 h）内" |
| 机制 | 只有性能数据却给机理结论 | 改为"可能与…有关，尚需…验证" |
| 未来工作 | 把计划写成已完成 | 移入"未来工作"并标未完成 |
