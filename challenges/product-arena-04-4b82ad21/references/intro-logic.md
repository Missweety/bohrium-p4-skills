# 引言与相关工作的逻辑骨架（可执行模板）

## 1. 四块结构与字数分配

| 块 | 回答的问题 | 篇幅占比 | 必须出现 |
|-|-|-|-|
| 研究背景 | 什么具体问题、为什么现在做、技术约束是什么 | 25% | 具体场景、量化约束、≥1 条引用 |
| 相关工作 | 已有哪几条路线、各自取舍与共同局限 | 35% | 分组维度、比较句、≥2 条引用/组 |
| 研究空白 | 哪一条件组合仍未被回答、由谁的局限推出 | 20% | ≥2 条已引局限、未覆盖条件 |
| 本文贡献 | 本文怎么做、证据在哪、边界在哪 | 20% | 方法要点、图表指针、边界 |

顺序不可颠倒；"研究空白"必须紧接"相关工作"，"本文贡献"必须逐条回应空白。

## 2. 背景段模板（忌空转）

```
在 <具体场景> 中，<关键任务> 需要在 <约束：精度/时延/成本/尺度> 下完成。
现有 <手段> 在 <条件> 下会 <具体失效表现>，例如 <可核验的现象或数值> [1]。
若不能解决 <该失效>，<下游后果>。
```

反例：
```
错：近年来，深度学习受到广泛关注，在诸多领域取得重要进展。
问题：无具体问题、无约束、无引用、可替换到任何论文。
```

## 3. 分组维度（三选一为主，可交叉）

| 维度 | 分组依据 | 比较点 |
|-|-|-|
| 问题设定 | 假设条件、输入形态、任务边界 | 谁覆盖了更弱的假设、谁的适用面更窄 |
| 方法路线 | 模型/算法族（如 物理模型 / 数据驱动 / 混合） | 精度、可解释性、数据需求、计算成本 |
| 数据与评价 | 数据集规模、标注方式、评价指标 | 结论是否可比、是否存在评测泄漏 |

每组写三句：**共同目标 → 各自取舍 → 共同局限**。共同局限就是下一步空白的原料。

```
模板：围绕 <目标>，已有工作可分为 <路线 A> 与 <路线 B>。A 在 <条件> 下 <优势>，
但 <代价> [2,3]；B 缓解了 <问题>，却依赖 <强假设> [4]。两者都未处理 <未覆盖条件>。
```

## 4. 缺口推导（三要素缺一不可）

```
gap = 已引文献局限（≥2 条引用） + 未覆盖的条件 + 该条件为何重要
```

| 缺口类型 | 推导句式 | 反例 |
|-|-|-|
| 条件未覆盖 | "上述方法均在 <条件 X> 下验证，尚未涉及 <条件 Y>[1,2]" | "很少有人研究 Y"（无引用、无理由） |
| 结论冲突 | "A 报告 <正效应>[1]，B 报告 <负效应>[2]，二者差异可能源于 <变量>" | "存在争议"（不说是谁的争议） |
| 代价不可接受 | "精度提升伴随 <成本> 上升[3]，在 <场景> 中不可行" | "效率仍然不足"（无量化、无引用） |
| 评测缺口 | "现有评测只覆盖 <指标>[4]，缺少 <指标>" | "评价不够全面" |

写作要求：每个空白句后面必须紧跟一句"本文如何回应"，否则删掉该空白。

## 5. 贡献条目模板（四要素）

```
本文 <动作：提出/构建/证明> <对象>，在 <条件/数据> 上 <结果>（证据：Figure N / Table N / Section N），
适用于 <边界>，不适用于 <明确排除的情形>。
```

校验清单（逐条打勾）：
- [ ] 有动作动词，不是"本文研究了……"这种无信息表述。
- [ ] 有证据指针，且指针在正文真实存在（图表编号/章节/具体指标）。
- [ ] 有边界，说明不适用的条件。
- [ ] 与某个空白一一对应（贡献数 = 空白数，或明确说明一条贡献回应多个空白）。
- [ ] 不含材料中不存在的数值或对比结论。

## 6. 段落级 claim 清单（写作前必做）

每段开头先写 3–5 条 claim，再展开成句：

```json
{"para": "P2", "claims": [
  {"id": "C2-1", "text": "物理模型路线依赖精确参数", "citations": ["[2]"], "evidence": "refs.bib key=xxx"},
  {"id": "C2-2", "text": "数据驱动路线在少样本下退化", "citations": ["[3,4]"], "evidence": "refs.bib key=yyy"},
  {"id": "C2-3", "text": "两路线都未覆盖高温工况", "citations": ["[2,3,4]"], "evidence": "三篇摘要的条件段"}
]}
```

写完用 `claim_citation_linker.py` 回扫，`status != ok` 的 claim 必须处理。

## 7. 自检顺序

1. 四块是否齐全且顺序正确。
2. 每个空白是否有 ≥2 条引用 + 未覆盖条件 + 本文回应。
3. 每条贡献是否有证据指针 + 边界。
4. 是否存在连续 3 句以上的逐篇罗列。
5. 是否存在"重要/广泛关注/意义重大"等无信息句。
6. 引用是否落在论断句而非段末。
