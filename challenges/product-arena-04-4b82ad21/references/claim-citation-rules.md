# 论断—引用匹配规则（claim → citation）

目标：让审稿人能对每一句做"这句凭什么这么说"的追溯。规则分**匹配、位置、强度、聚合**四类。

## 1. 论断类型与最低证据

| 论断 | 例子 | 最低证据 | 不满足时 |
|-|-|-|-|
| 领域现状 | "该反应在 300 °C 以上选择性下降" | 1 条直接研究报告 | 标 `missing_citation` 或删 |
| 方法存在 | "已有工作采用 X 路线" | 1 条代表文献（可 `title_only`） | 降级为"据我们所知" |
| 方法性能 | "X 路线在 Y 数据上达到 Z" | 该文献原文数值 | 不得转述未读到的数值 |
| 局限 | "X 依赖精确参数" | 该文献自述或对照实验 | 标为作者判断 |
| 空白 | "尚未在 W 条件下验证" | ≥2 条已引文献的条件范围 | `gap_unsupported` |
| 本文结果 | "本文方法提升 12%" | 本文结果表/图 | 不得出现该数字 |

## 2. 引用位置

- 引用贴在**承载论断的句子**上（英文句号前、中文句号前），不是段末、标题或图注。
- 一句多引：`[3,5]` 表示两条文献共同支撑同一论断；若分别支撑不同子句，应拆分或写明
  "A 路线[3]与 B 路线[5]"。
- 多句一引：同一结论连续多句时，至少第一句给出引用；不得整段只在末尾挂一条。
- 引用编号与文献表必须一一对应，编号制全篇统一（见 `citation-integrity-auditor`）。

## 3. 转述强度（不得越级）

| 原文表述 | 允许转述 | 禁止转述 |
|-|-|-|
| associated with / correlated | 与……相关 | 导致、引起 |
| suggests / indicates | 提示、可能表明 | 证明、证实 |
| in vitro / 在小鼠中 | 在体外/动物模型中 | 在人体中 |
| under condition X | 在 X 条件下 | 普遍地、在任何条件下 |
| preliminary / preprint | 初步结果/预印本 | 已被广泛验证 |

审稿人视角检查：把转述句与文献题名/摘要并排读，若转述比原文更强，必须回退。

## 4. 引用聚合（避免堆砌）

允许：
```
已有研究从物理模型[1,2]与数据驱动[3,4]两条路线展开，前者精度高但依赖参数，后者适应性强但少样本退化。
```
不允许：
```
许多研究对该问题进行了探讨[1-6]。
```
后者的三个问题：无具体结论、无法判断哪条支撑哪句、读者无法复核。

判断阈值（与脚本一致）：
- 单句 ≥3 条引用且句中没有区分性表述（"前者/后者/分别/相较"）→ `stacked`。
- 句子去掉引用后剩余内容 <12 字或只是"已有研究表明" → `decorative`。
- 连续 3 句均为"X 做了 A[ n ]"结构 → 逐篇罗列，需合并。

## 5. 本文贡献与证据的绑定

| 贡献表述 | 必须绑定的证据 | 校验方式 |
|-|-|-|
| "提出 M 模块" | 方法节编号 + 结构图 | 正文存在该节与图 |
| "在 D 上达到 P" | 结果表行 + 指标名 | 表中有该数值且口径一致 |
| "优于基线 B" | 对照实验 + 显著性说明 | 有同条件对比，非跨数据集比较 |
| "适用于 S 场景" | 该场景的实验或明确论证 | 无实验则改为"设计上适用"并标作者判断 |

`contribution_map.csv` 列：`contribution, evidence_pointer, boundary, verified`。
`verified=false` 的贡献不得进入最终正文，或改为 `pending_evidence` 并在 `limits` 说明。

## 6. claim_map 字段约定

| 字段 | 含义 |
|-|-|
| `sid` | 句子编号（S001 起，全文唯一） |
| `section` | 所属标题（研究背景/相关工作/研究空白/本文贡献） |
| `role` | background / related / gap / contribution / result |
| `citations` | 该句引用 token 列表 |
| `status` | ok / needs_citation / gap_unsupported / stacked / decorative / missing_ref / contribution_needs_evidence |
| `action` | 可直接执行的处理建议 |

## 7. 常见失败与修法

```
失败：引言第一段用"随着……的发展"开头，第二段开始逐篇列作者。
修法：第一段直接给具体场景与量化约束；第二段改为按路线分组，每组末尾写共同局限。

失败：空白句写"目前尚无相关研究"，但只引了 1 篇且该文覆盖了所述条件。
修法：核对被引文献的条件范围；若已覆盖，删掉该空白，改写为新的未覆盖条件。

失败：贡献写"显著提升了性能"，但结果表无显著性检验。
修法：改为"在 D 上由 A 提升至 B（Table 2）"，删去"显著"。

失败：相关工作引了 20 篇但正文贡献只回应其中 3 篇。
修法：删去与本文问题无关的条目，只保留构成空白推导链的文献。
```
