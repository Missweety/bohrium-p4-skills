# 交付前自查清单 · 科研图表解析

## 契约

- [ ] `result.json` 含 `case_id` 与 `output_contract` 声明的全部字段
- [ ] `status` 为真实运行状态，不是占位值
- [ ] `sources` 非空，每条可定位（路径 + p.N/sec.N/sent.K 级锚点）
- [ ] `uncertainty` 列出未决项，或明确写 none
- [ ] `change_log` 至少一条，记录实际做过的动作

## 内容

- [ ] 先识别输入材料和问题边界，再按题目要求完成解析动作
- [ ] 为关键结论保留页码、段落、字段或图表定位（每条数值可复核）
- [ ] 对未报告、无法判断和材料冲突明确说明
- [ ] 读准：判别坐标轴类型（线性/对数/双轴）、刻度起点与间隔、单位量级
- [ ] 提全：完整还原曲线、数据点、误差线、峰位与峰强、显著性标记、比例尺、子图编号，不把非数据元素当数据
- [ ] 讲清：趋势与统计结论有图中证据支撑，并区分“图中直接可读”“合理推断”“无法确定”
- [ ] 交出：输出带单位、精度和误差范围的结构化数据（如 CSV 或结构化字段）并保留可复核的读取路径；多子图场景不跨子图错配编号
- [ ] 结果写入 /app/output/result.json，含 case_id 与全部 output_contract 字段

## 红线

- [ ] 未违反：不把 mV 当 V、不把对数轴当线性轴
- [ ] 未违反：未给像素的其他图注明确列缺口，不能构造，也不是要求补齐的隐藏任务
- [ ] 未违反：不得用预制答案或预生成正式答案代替实际运行
- [ ] 未违反：实际输入文件和原论文是事实依据，不依据错误的领域标签补造数据
- [ ] 未违反：不得伪造 benchmark 分数或缺失的科学数据
- [ ] 未违反：部分完成的结果必须标明其限度

## 可核验指标

- [ ] 读数准确率（提取数值与原图一致的比例）
- [ ] 图表元素还原完整率（坐标轴/刻度、图例、系列、数据点、误差线、显著性标记、比例尺、图注、子图编号）
- [ ] 坐标轴类型与单位量级判定正确率
- [ ] 带单位+精度+误差范围的数值占比
- [ ] 证据回指闭合率（结论可定位到图中位置的比例）
- [ ] 图例-系列与子图编号匹配正确率
