# 交付前自查清单 · 学术汇报内容组织

## 契约

- [ ] `result.json` 含 `case_id` 与 `output_contract` 声明的全部字段
- [ ] `status` 为真实运行状态，不是占位值
- [ ] `sources` 非空，每条可定位（路径 + p.N/sec.N/sent.K 级锚点）
- [ ] `uncertainty` 列出未决项，或明确写 none
- [ ] `change_log` 至少一条，记录实际做过的动作

## 内容

- [ ] 把「这次汇报要达成什么」转成可检查的报告目标，并据此确定页数、时长与结论强度
- [ ] 识别听众的先验知识、关注点与可能质疑，据此决定背景铺垫比例、术语解释范围与证据展示深度
- [ ] 在「问题—方法—结果—结论」主骨架上安排取舍与铺垫，形成有起承转合的讲述路径，而非按论文目录逐节搬运
- [ ] 每页确定唯一主张、支撑证据与图形表达，把一段文字压成一句可讲的结论，并标注该结论的证据强度
- [ ] 做问答准备：预判机制、数据、对照与局限类追问，准备可引用的页面、备用页与口径一致的回答要点
- [ ] 按固定听众/时长/页数控制页面节奏与张数；备注与页面结论对应且不重复页面文字
- [ ] 在模板约束内成稿并导出 PDF/PNG，逐页核对渲染、字体与母版合规
- [ ] 交付取舍过程记录（哪些内容被舍去、为什么），使从源材料到成稿的组织过程可被他人复核

## 红线

- [ ] 未违反：不得把摘要与 Results 逐段搬成页面；页数与讲述时长不得脱节
- [ ] 未违反：不得出现页内图表与结论不对应、公式与引用编号错位
- [ ] 未违反：不得只写一句口号式结论；结论强度必须与证据匹配并显式标注
- [ ] 未违反：不得覆盖模板字体、配色与母版，导出后不得字体被替换、配色不合规
- [ ] 未违反：不得编造运行结果、benchmark 分数或未核验的结论

## 可核验指标

- [ ] 报告目标覆盖度 = 有目标支撑的页数 / 总页数，目标 100%（且目标数 ≥ 1）
- [ ] 单页唯一主张覆盖率 = 只有一个明确主张的页数 / 总页数，目标 100%
- [ ] 听众适配项落地率 = 已落实的背景铺垫/术语解释/证据深度项数 / 预期项数，目标 100%
- [ ] 问答准备覆盖率 = 有预判问答与备用页的预期问题数 / 预期问题总数，目标 100%
- [ ] 证据强度标注缺失页数 = 0
- [ ] 页数 ≤ 固定上限且按讲述语速估算的时长偏差 ≤ 10%
