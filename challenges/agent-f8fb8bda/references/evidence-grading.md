# 证据分级与边界表述

`scripts/evidence_rank.py` 实现本文件的评分规则。分级只是**可复核的排序**，不是对研究质量的最终裁决；
它的作用是让"这条结论有多硬"在报告里显式可见，并让读者能按同一规则重算。

## 1. 评分构成

| 维度 | 取值 | 分值 |
|-|-|-|
| 来源类型 | peer_reviewed 3.0 / conference 2.5 / review 2.0 / preprint 2.0 / thesis 1.5 / report 1.5 / dataset 1.5 / web 0.5 / unknown 0 | 基础分 |
| 直接性 | direct +2.0 / indirect +1.0 / background 0 | — |
| 研究设计 | experimental 1.0 / rct 1.0 / meta_analysis 1.0 / cohort 0.5 / modeling 0.5 / none 0 | — |
| 时效 | 距 `--as-of` 年 ≤ `--window`（默认 5）+0.5 | — |

等级：`A ≥ 5.0`、`B ≥ 3.5`、`C ≥ 2.0`、`D < 2.0`；缺 `quote`（<12 字符）或缺 `locator` → `X` 不可采信。

说明：

- 综述（`review`）是证据的二次综合，直接性通常填 `indirect`，不要凭"综述权威"抬高等级。
- 预印本与同行评议同分是刻意的：**本 Skill 不给未核实的质量差异打高分**，只在措辞上区分。
- 时效只加 0.5，避免"新即好"覆盖方法与直接性差异。
- 单篇材料的等级上限由 `source_type` 决定，不能靠叠加设计分把 `report` 拉成 A 级共识。

## 2. 覆盖判定

| `verdict` | 条件 | 报告措辞 |
|-|-|-|
| `covered` | 该子问题至少有 1 条 A 或 B | "现有材料支持……"（多来源）/ "一项材料报告……"（单来源） |
| `weak` | 只有 C/D | "有材料提及，但证据间接或较弱……" |
| `not_covered` | 无任何可采信证据 | "库内材料未覆盖……"，并附检索记录 |

`single_source: true` 表示该子问题虽有 A/B 证据，但只来自 1 个文件。此时：

- 允许写"一项材料报告 X"；
- 禁止写"材料一致表明 X"、"研究普遍认为 X"、"已证实 X"；
- 必须在"不确定性与限制"里单列该子问题。

## 3. 冲突

`conflicts` 由同一子问题同时存在 A/B 级 `support` 与 `refute` 触发。处理要求：

1. 双方都写进"冲突与反证"小节，各带定位与原文。
2. 差异归因只能来自材料原文：样本、条件、测量方法、时间窗。
   材料没写原因就写"材料未说明差异来源"。
3. 不得用等级高低"裁决"冲突（A 级 vs B 级不等于 A 级对）；
   等级只用于说明"哪一方证据更直接"，不用于宣布结论。
4. 若冲突导致该子问题无法回答，`verdict` 降级为 `weak` 并在 `gaps` 记录。

反例：

| 写法 | 问题 |
|-|-|
| "综合来看，X 的效果更好（88.6% vs 74.1%）" | 取一方数值当结论，抹掉冲突 |
| "两篇文献结论不一致，尚存争议" | 没给定位、没给差异维度，读者无法复核 |
| "A 级证据优先，故取 88.6%" | 用分级替代证据评估 |

## 4. 反证（counter-evidence）

`stance: refute` 或 `mixed` 的证据必须出现在正文，即使它等级较低。要求：

- 在"冲突与反证"小节逐条列出：证据 id、定位、它反驳的具体主张；
- 若反证只覆盖子集（如不同人群），写明适用边界，不据此否定全部结论；
- 若最终结论仍偏向一方，必须写清"为何在给定材料范围内采信该方向"，且理由只能是证据直接性/一致性，
  不能是"多数票"以外的臆断。

## 5. 研究空白

只允许两种合法来源：

| `basis` | 含义 | 必须附 |
|-|-|-|
| `not_covered` | 子问题无任何可采信证据 | 子问题 id + 已执行的检索式 |
| `empty_query` | 某个检索式在全部材料中零命中 | 检索式 + 检索范围 + 文件数 |

禁止写法："该领域仍有广阔研究空间"、"相关研究较少"（未给检索记录）、
"受数据限制"（未说明缺哪个字段/哪批样本）。

可以写的样子：

> 子问题 Q4（长期效应）在 9 份材料中未覆盖：检索式 "long-term"、"follow-up"、"5-year"
> 在 `materials/` 全目录零命中；现有材料均为 ≤6 个月的短期观测。要回答该问题，需要纳入
> 随访期 ≥2 年的原始研究或队列数据。

## 6. 待验证清单

每条写成一个可执行动作 + 判定标准：

```json
{"item":"验证 X 在条件 C2 下是否仍成立","needs":"C2 条件下的原始测量数据",
 "would_upgrade":"Q2 从 B 升到 A","blocks":"结论 3 的外推边界"}
```

禁止："建议后续深入研究"、"需要更多实验"这类无法执行的话。
