# 对照设计与依据分级（design-controls）

本文件是 `SKILL.md` 第 4–9 步的判据来源：对照怎么配、参数依据怎么标、样本量怎么说、风险怎么写成
可执行的止损。所有条目都要能落到 `plan.json` 字段，方便脚本核对。

## 1. 对照矩阵

| 对照类型 | 排除的混杂 | 何时必需 | 不合格写法 |
|-|-|-|-|
| `negative`（空白/未处理） | 基线漂移、仪器本底、非特异信号 | 几乎所有实验 | 只写"对照组"，不写处理了什么/没处理什么 |
| `vehicle`（溶剂/载体） | 辅料、溶剂、涂覆工艺本身的效应 | 处理以溶液/载体递送时 | 有溶剂却只用空白，把溶剂效应算进处理效应 |
| `positive`（已知有效） | 体系/检测是否具备响应能力 | 新体系、新检测、阴性结果解释 | 用"文献里有效"代替本批阳性对照 |
| `dose_gradient`（≥3 水平） | 偶然阈值、剂量无关的假阳性 | 声称"剂量依赖/增强/抑制"时 | 两水平就宣称剂量效应 |
| `sham`（假操作） | 手术/器械/处理流程本身 | 动物或器械干预 | 与 vehicle 混用 |

规则：至少两类对照，且每条 `controls[].excludes` 必须写出"排除哪类混杂"。声称因果时，
必须有一个对照能排除"流程本身"或"载体本身"。删对照省预算时，写清牺牲了哪种归因能力。

## 2. 变量操作化清单

每个自变量写 `levels`（具体取值或类别）与 `operational`（怎么设到这个水平）；
每个因变量写 `instrument`（型号/方法）、`unit`、`sampling`（几个时间点/几个视野/如何取平均）；
每个混杂写 `control`（随机化、区组、配对、归一化、纳入排除标准），**"注意保持一致"不算控制手段**。

判据：换一个没参与设计的人拿着变量表，能独立复现每一组的设置与每一次测量。

## 3. 参数依据分级

| `basis` | 含义 | 必备字段 | 脚本如何核 |
|-|-|-|-|
| `equipment_spec` | 来自设备手册/量程 | `source` 指向材料中的手册页/型号 | 取值须在材料文本中出现 |
| `organizer_contract` | 题面/组织方给定的价格、排期、约束 | `source` 指向题面条目 | 取值须在材料文本中出现 |
| `literature_in_material` | 材料内文献给出的条件 | `source` 指向该文献段落 | 取值须在材料文本中出现 |
| `assumed` | 无来源，凭经验假设 | 必须写 `assumption`（假设内容）+ `sensitivity`（±范围时结论是否翻转） | 计入 `assumed_count` 并要求进确认项 |

**禁止**：`basis` 写 `preexperiment`/`pilot`；把假设值写进 `source` 假装有出处；
把两个来源不同的值混用却不标冲突（冲突时按保守值做预算并记 `conflict`）。

## 4. 样本量与功效

- `basis=power`：必须给 `alpha`、`power`、`effect_size`、`sd` 与效应量来源（材料内文献）。
  只写"n=3 是惯例"属于 `assumed`。
- `basis=assumed`：给出区间（如 n=6–10）与"该 n 能检出的最小差异"，并说明这是假设。
- `basis=organizer_contract`：题面直接给定 n 时使用，仍需写"能否支持主终点"的判断。
- 技术重复 ≠ 生物学重复：必须分别写 `technical_replicates` 与 `biological_replicates`。

## 5. 时间与成本算术（脚本会算）

```
耗材小计 = Σ(数量 × 单价)          → 必须等于 budget.total（±1 容差）
budget.total ≤ budget.cap
设备占用 = Σ(单次占用 h × 批次数)  → 必须 ≤ 该设备 available_h
schedule.total_hours = sessions × hours_per_session  → 必须 ≤ window_hours
```

算不平的处理顺序：先改设计（合并批次/减辅助指标）→ 再改排期 → 最后才减 n，并写明功效影响。
**永远不要改数字让式子成立**。

## 6. 风险预案写法

每条风险五段式，缺一段就不算预案：

```json
{"mode": "无信号", "indicator": "阳性对照信号 < 空白 2 倍",
 "threshold": "连续 2 批出现", "stop_loss": "停止该批次，排查试剂活性",
 "fallback": "更换试剂批号并重跑阳性对照；仍无信号则改用方法 B"}
```

至少覆盖：无信号、污染/批间差、重复性差（CV 超限）、样本不足、设备不可用。
`indicator` 必须是**实验过程中能观测到的量**，不是"结果不好"。

## 7. 三版候选的比较口径

A 基线、B 预算约束、C 功效优先。三版必须在同一算口径下给 `n_per_group/cost/hours`，
并各写 `changes`（相对基线改了什么）。推荐理由只能是：在预算与时间窗内最大化"主终点可检验性"，
不允许写"更先进/更全面"这种无法核对的理由。若没有一版同时满足约束，明确写出牺牲项。

## 8. 反例集

| 反例 | 问题 | 合格写法 |
|-|-|-|
| "设置对照组" | 无类型、无排除目标 | "vehicle 组：同体积溶剂，同时长，排除溶剂效应" |
| "温度 80 ℃左右" | 无量程依据、无越界处置 | "80 ℃（设备量程 40–120 ℃，手册 p.3）；>90 ℃ 改程序降温" |
| "n=3，符合惯例" | 依据不成立 | "n=3 为技术重复；生物学重复 n=8（功效 0.8，效应量取自材料文献）" |
| "预算约 5000 元" | 无小计、无币种 | "耗材 3,180 + 耗材 B 1,000 = 4,180 CNY ≤ cap 5,000" |
| "注意避免污染" | 无指标无止损 | "空白孔 OD>0.1 连续 2 批 → 停批、换试剂批号、重跑阳性对照" |
| "已做预实验确定条件" | 编造状态 | "条件为 assumed（无预实验数据），敏感性 ±10%" |
