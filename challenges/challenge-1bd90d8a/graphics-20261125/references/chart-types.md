# 图型决策、统计口径与数据卫生

本文说明 `plan_figures.py` 的确定性规则。工单显式指定图型时优先，其次看任务文本中的
关键词，最后按数据结构自动选择。所有选择都写入 `chart_plan.json` 的 `decision`，
不静默换图。

## 1. 自动决策顺序

1. 存在日期/时间列且有数值列 → `line`（按时间排序）。
2. 数值列 ≥ 2 且无分类列 → `scatter`（前两列数值）。
3. 数值列 = 1：
   - 有分类列 → `bar`（分类 × 组均值）；
   - 无分类列 → `hist`。
4. 数值列 ≥ 2 且第一列是唯一行标签、其余为数值条件列 → `heatmap`（矩阵）。
5. 分类列 ≥ 2 → `grouped_bar`（x = 第一分类，系列 = 第二分类）。
6. 其余 → `panel`：每个数值指标一个面板（最多 4 个）。

补充：
- `--x/--y/--group` 一律先做列名归一化（大小写、空格/下划线/括号差异、唯一前缀），
  命中失败会列出全部列名并退出 1，不猜列。
- 任务文本中的“柱状图/分组柱状图/折线图/散点图/直方图/箱线图/热图/组合图”会转成
  `--intent`；没有关键词时 `auto`。
- `--intent heatmap` 找不到两因素/矩阵结构时退回 `grouped_bar`/`bar`，并在
  `warnings` 与图注声明。

## 2. 柱状图 / 分组柱状图

- 柱高 = 组算术均值；组内非数值/缺失不计入 `n`。
- 误差线：`sd` = 样本标准差（n−1）；`sem` = SD/√n；`ci95` = mean ± 1.96·SEM；
  `none` = 不画。`n < 3` 时误差线为 `null` 并在图注说明。
- y 轴默认从 0 起；只有显式改图指令能把下界抬高，且 `pinned=true`、图注写“截断显示”。
- 单系列不显示图例；分组柱状图的图例项由 `series[].label` 逐字生成。
- 每组柱上方标注数值（按量级保留 2–4 位有效小数：21.74、1.26、0.453），单位见轴标签。

## 3. 汇总表直接使用

若源表已有均值列 + `sd`/`sem`/`CI` 列 + `n` 列（列名如 `mean`、`sd`、`n`），
`plan_figures.py` 识别为 summary 表，直接把行当作组统计量，**不再二次求均值**。
误差线口径取源表声明的列；`n` 原样带入。无法确定列含义时退回原始数据聚合，
并在 `uncertainty` 说明。

## 4. 折线图 / 散点图

- `line`：按 x 排序；同一 x 有重复时按组求均值，点数 = 唯一 x 数；
  误差线口径同上；`n<3` 不画。
- `scatter`：每个源行一个点，x/y 均为数值列；`element_map` 的 `point:*` 记录行号、
  x 列与 y 列。不去重、不抽样；点很多时图注给出总点数，便于判断可读性。

## 5. 直方图

- 10 个等宽箱，范围覆盖非空数值的最小值到最大值；箱高 = 计数。
- `element_map` 的 `bin:k` 记录 `[lo, hi)`、计数与落入该箱的源行号。
- 空箱保留在图上，计数为 0。

## 6. 箱线图

- Tukey 规则：`q1 - 1.5·IQR` 到 `q3 + 1.5·IQR` 为须；须外为异常点。
- 箱体记录 min/q1/median/q3/max/n/outliers 与源行号；不剔除异常值。

## 7. 热图

两种来源：
- 矩阵：第一列唯一行标签 + 多列数值 → 每个单元格一个数值；
- 长表：`x`（列变量）+ `group`（行变量）+ `y`（数值），同一 (行, 列) 多行时取均值并
  记录全部源行号。

颜色使用离散 Viridis（10 级）；图例为颜色刻度，标出 min/max 与单位。
单元格数值同时写入 `element_map` 的 `cell:r|c`，可供逐格复算。

## 8. 多面板

`panel` 图型为每个数值指标建立一个面板（最多 4 个），共享类别轴；
每个面板有独立标题、轴与图元 id（`panel:A`、`panel:B`…）。超过 4 个指标时
保留前 4 个并在 caveat 声明。

## 9. 单位与列名

`tableio.parse_header` 识别这些形式并拆成 `name` + `unit`：
`体重(g)`、`[mg]`、`/kg`、`length_mm`、`expression_mg_ml`（→ `expression`, `mg/ml`）。
轴标签写 `变量 (单位)`；单位缺失时轴标签只有变量名，并在 caveat 写“单位待确认”。

## 10. 数据卫生

| 情况 | 处理 | 记录位置 |
|-|-|-|
| 空值 / `NA` / `N/A` / `-` / `<LOD` / `>LOQ` | 不计入统计，不插补 | `spec.missing`、图注、`element_map.series.source_rows` 不含该行 |
| 完全重复行 | 保留（默认不去重），计数与行号 | `spec.duplicates`、图注 |
| IQR 异常值 | 保留并标记，不自动删除 | `spec.outliers`、图注 |
| 非数值文本混入数值列 | 当作缺失并警告 | `data_profile.warnings`、`uncertainty` |
| 短行/多余单元格 | 补空/截断，计数 | `data_profile.short_rows/extra_cells` |
| 类别 > 12 | 前 11 类 + `Other` | caveat、图注 |
| 常量列 | 忽略并警告 | `data_profile.warnings` |

## 11. 显著性

只在源表存在 p 值列、显著性标记列或图注原文时转写；不运行检验、不计算 p 值、
不推断“显著”。`spec.significance_provided=false` 时图注明确写“未提供显著性检验”。

## 12. 字体与长标签

- 有 CJK 字体（Noto Sans CJK / Source Han / PingFang / Hiragino / Arial Unicode 等）
  时直接使用；缺失时保留原文 `<text>`，在 `limits` 记录“可能显示为方框”，不替换英文。
- 标签宽度超过轴宽 60% 时自动换行（最多 3 行）；仍超宽则旋转 30°/45°/90°；
  旋转后仍可能重叠时减少刻度密度并保留全部类别文字在 SVG 中。
