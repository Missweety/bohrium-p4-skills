# 论断切分：规则与边界

目的：把"一段话"变成"能被逐条判定真假与依据"的最小单元。切分粒度决定证据表能否复核。

## 1. 切分规则

1. **一句一断言**：一个句号/分号内出现两个独立可核事实，就拆成两条（`C3a`、`C3b`）。
2. **主谓宾齐全**：省略主语的句子先补全主语，避免"该结果"指代不明。
3. **保留限定条件**：温度、剂量、人群、时间窗属于论断的一部分，不能挪到证据栏。
4. **因果与相关分开**：`X 导致 Y` 与 `X 与 Y 相关` 是两条不同论断，不可合并。
5. **比较句拆出比较对象与方向**：`A 高于 B` → 对象 A、B，方向 higher。
6. **方法性/过渡性句子不建论断**：不承载事实的句子（"本节介绍…"）标 `non_factual`，不进证据表。

## 2. 论断类型

| type | 说明 | 常见证据要求 |
|-|-|-|
| `factual` | 数值、事实、现象 | 原文片段 + 精确位置 |
| `causal` | X 导致/影响 Y | 需实验或机制证据；仅有相关性时降级 |
| `comparative` | A 与 B 的高低/差异 | 两侧数值 + 统计检验（若有） |
| `method` | 本研究采用的方法 | 方法段原文 |
| `claim_of_consensus` | "普遍认为/共识" | 需综述/指南级别证据，单篇不足 |

## 3. 边界案例

- 原文："处理组降解率为 12.4%，高于对照组的 3.1%（n=24，未做显著性检验）。"
  切分：`C1` 处理组 12.4%；`C2` 对照组 3.1%；`C3` 处理组高于对照组；`C4` 样本量 24。
  `C3` 的表述不得写"显著高于"，因原文明确未做检验。
- 原文："Chen 等（2021）报告类似趋势，但样本量仅 6 例。"
  切分：`C5` Chen 2021 报告类似趋势（`moderate`，二手引用）；`C6` 该研究样本量 6（`factual`）。
  不得把 `C5` 写成"多项研究一致"。
- 原文两段结论相反：不合并成一条"存在争议"，而是 `conflict` 一条 + 两条证据；待核项写明差异来源（人群/剂量/终点）。

## 4. 自检

- 每条论断能否用"是/否/材料未涉及"回答？不能就是没切干净。
- 把论断单独交给别人，能否在 1 分钟内定位到原文位置？不能就补 `locator`。
- 成稿中每个含数字或因果的句子，是否都有 `C` 编号？没有就补或删。
