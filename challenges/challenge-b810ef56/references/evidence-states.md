# 证据三态与强度：判定口径

所有实质性论断只有三种状态，不允许"看起来有引用"这种模糊地带。

| 状态 | 判定条件 | 证据栏 | 成稿允许的写法 |
|-|-|-|-|
| `supported` | 材料中至少一条原文片段直接支持该论断，且支持范围覆盖论断的主语、方向与强度 | 必填：`quote`（逐字）+ `source` + `locator` | 按强度使用相应动词与限定语 |
| `not_covered` | 材料中没有相关陈述 | 必须为空；`note` 记录检索的关键词与范围 | 只能写成"本研究未涉及/材料未提供"，或删除 |
| `conflict` | 材料内部对同一问题给出相反或不一致的陈述（数值、方向、结论） | ≥2 条，位置与原文都要留；`note` 写明待核问题 | "材料间存在分歧（C7）"，不选边、不定论 |

## 1. 三态边界（最容易出错的地方）

1. **只支持了一半**：原文说"在 298 K 下活性相近"，论断写"在所有温度下活性相近" → 不是 `supported`，
   改写论断缩到 298 K，或标 `partial_support` 并降级表述。
2. **方向相反**：原文"未见显著差异"，论断写"略有提升" → `conflict`（如果是同一实验的另一种表述）
   或 `not_covered`（如果材料根本没做该比较）。不许折中成"略有提升"。
3. **相关 vs 因果**：原文"与…相关"，论断写"导致" → 证据强度不足以支撑因果，改写为
   "associated with / 与…相关"。
4. **个体 vs 总体**：单中心 n=24 的研究 → 不能写"领域共识"。
5. **体外/动物 → 人群**：跨物种外推必须有材料明确说明，否则降级为"在细胞模型中"。
6. **二手转引**：材料只给了综述对原始研究的转述 → 标 `note: secondary_citation`，
   强度不超过 `moderate`，并写入待核（需回查原始文献）。

## 2. 强度分级

| strength | 适用证据 | 典型措辞（中/英） |
|-|-|-|
| `strong` | 多研究一致 + 大样本/随机对照 + 系统综述或指南 | 一致表明 / consistently shows |
| `moderate` | 单项设计良好的原始研究，或权威综述与原始研究一致 | 表明 / indicates |
| `weak` | 单中心小样本、观察性、仅摘要、机制推测、个案 | 提示 / may suggest |
| `none` | 无证据（`not_covered` 或纯推测） | 不作事实陈述 |

强度只描述**证据**，不描述结论的重要性。强度为 `weak/none` 时出现"证明/证实/必然/显著优于/proves"
一律判为过度断言。

## 3. 限定语对照（写作时直接替换）

| 过度表述 | 相称表述 |
|-|-|
| X 导致 Y | X 与 Y 相关；在…条件下 X 可能促进 Y |
| 证明 X 有效 | 现有证据提示 X 在该人群中可能有效 |
| 所有患者 | 纳入的 24 例患者 |
| 显著提高 | 提高（材料未报告统计检验，或 p=…） |
| 领域共识 | 部分研究（或某综述）认为 |
| 机制是… | 可能机制包括…；机制尚未明确 |

统计显著性只能引用材料给出的检验方法与 p 值；材料没给就不能写"显著"。

## 4. 反例（评审最常扣分）

1. 引用编号对得上，但引文只支持前半句 → 拆句分别标注。
2. 用 `[12]` 挂在段末，段内 5 句只有 1 句被支持 → 逐句标注，其余转 `not_covered`。
3. 两组数值冲突时取平均或取"更合理"的一个 → 必须并列 + 待核，不裁决。
4. 把 `not_covered` 写成"文献报道较少"来暗示存在支持 → 明确写"材料未涉及"。
5. 引用条目凭空补 DOI/页码 → 一律 `missing_citation`。

## 5. 待核清单的最小字段

每条 `conflict` 与"需人工确认"项至少写清：问题、两方证据位置、需要谁/用什么材料确认、确认前正文如何措辞。
缺任一项即视为"未标注不确定性"。
