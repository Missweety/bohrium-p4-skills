# PDF 结构元素判别与反例

## 1. 元素清单（解析必须逐项交代有无）

| 元素 | 判别线索 | 落盘字段 | 缺失时 |
|-|-|-|-|
| 标题 | 首页最大字号行；跨栏居中；常含冒号/破折号副标题 | `document.title` | 留空 + uncertainty |
| 作者/单位 | 标题下 1–4 行，含逗号分隔人名、`@`、上标数字/字母 | `authors[]` | 留空，不猜 |
| 摘要 | `Abstract` / `摘要` 标题后到下一标题前 | `sections[]` 中 `number:""` | 标 missing |
| 章节标题 | 编号 `1` `2.3` `2.3.1`、全大写短行、Markdown `#` | `sections[]` | — |
| 正文段落 | 连续长行，行尾多为逗号/连字符 | `blocks[type=body]` | — |
| 题注 | `Figure 1.` `Fig. 2a` `Table 3` `图 2` `表 1` 起首 | `figures[]` / `tables[]` | 标 `caption: null` |
| 表格体 | 多列对齐、大量数字、`±`、`−` | `tables[]` + CSV | 标 `image_only` |
| 公式 | 行末 `(1)` `(2a)`；含 `=`、希腊字母、上下标 | `equations[]` | — |
| 脚注 | 页底、`*` `†` `‡` 起首、小字号 | `footnotes[]` | — |
| 参考文献 | `References` 标题后，条目以 `[1]` 或 `1.` 起首 | `references[]` | 标 `missing` |
| 页眉页脚 | 在 ≥60% 页面首/尾 2 行重复（数字归一后相同） | `furniture[]` | — |

`scripts/doc_structure.py` 只做候选判别，最终 `type` 由 Agent 按本表复核，误判写入 `changes`。

## 2. 阅读顺序规则（按优先级）

1. 单栏：从上到下，先正文后脚注。
2. 双栏：跨栏块（标题、摘要、宽表、宽图注）先读，再 **左栏自顶向下**，再 **右栏自顶向下**。
3. 跨页续接：上一页末段以逗号/连字符结尾且下一页首段小写起首 → 合并为一个 block 并记
   `continued: true`，两页页码都写进 `lines`。
4. 边注/浮动框：与正文栏分离，标 `type: marginalia`，不插入正文句间。
5. 顺序不确定（多栏信号高、poppler 行序可疑）→ 该页 `reading_order_confidence: low`，
   在 `uncertainty` 写明"本页顺序未经视觉复核"。

## 3. 表格重建规则

- 首行=表头；多层表头用 `header_rows: 2`，并保留原始两行文本（不要只留拼接结果）。
- 合并单元格写 `spans: [{"r":1,"c":2,"rowspan":1,"colspan":2}]`；无法判定归属时整行 `uncertain: true`。
- 跨页续表用 `continued_from: table_3_p4`，**不合并成一张 CSV 冒充单表**，两张都保留。
- 空单元格与缺失单元格不同：空写 `""`，缺失（原表无此格）写 `null` 并在 `notes` 说明。
- 数字保留原文精度与符号（`−0.12`、`1.3 × 10⁻⁴`），不做换算、不补单位。

## 4. 公式与特殊字符

- 保留 Unicode 原字符：`α β γ Δ σ ± × ÷ ≤ ≥ ≈ ∝ ⁻¹ ² ₀ ₁`；不做"看起来合理"的 LaTeX 猜测。
- 行内公式随段落保留；独立公式按编号入 `equations[]`，同时保留整行原文以备对照。
- 上下标丢失时标 `sub_sup_lossy: true`，不自行推断（如 `cm2` 不得写成 `cm²` 而不标注）。

## 5. 反例（出现即判不合格）

| 错误做法 | 正确做法 |
|-|-|
| 把 `1. 引言` 与下一行正文合成一句 | 标题单独成 block，正文另起 |
| 把页眉 "J. Phys. Chem. 2023, 127" 混入正文 | 识别为 furniture，移出正文 |
| 双栏时左右栏交替读取产生"半句 + 半句" | 按栏顺序读，跨栏块单独处理 |
| 表格合并单元格用上一行值填充 | 写 `spans`，或标 `uncertain` |
| 扫描件用领域常识"补"出 Methods 段落 | 标 `unreadable_pages` 并给替代路径 |
| 抽不到 DOI 就写"该文未提供 DOI" | 写"解析结果中未见 DOI 字段"，进 `uncertainty` |

## 6. 已知边界

- `pdftotext -layout` 不提供字符坐标，多栏判据只是**弱信号**，不作事实断言。
- 图内文字、图片型表格、公式的数学语义不在本 Skill 范围（仅作结构元素定位）。
- DOCX 无分页信息时 `page` 用 `s1`（节序号）替代，并在 `document` 说明。
