# 方法：年度趋势、阶段与主题演化

## 1. 口径先写清

- **年份**只取三处：题录字段 `year`、正文首页明确来源（`Year:` / 出版年）、题录表列。缺失即
  `null`，**不用文件 mtime、卷期号或上线日期补**；`missing_year` 单列，且不进入年度表。
- **产出量**按"纳入文献数/年"，不是数据库命中数。去重后计数；重复版本只保留一条并在
  `screening.duplicates` 可查。
- **时间窗**由 `year_from/year_to` 限定；未给定时用文献集实际最小/最大年份，并在报告写清。
- 年度表每行都带 `sources` 编号，任何人可用 `matrix.csv` 重算 `count`。

## 2. 阶段划分

- 将年份升序排列，按**累计文献数**均分为至多 3 段；每段至少含 1 个年份，不产生空段。
- 只有不同年份数 ≥3 时才分 3 段；否则按实际年份输出，并在 `limits` 说明"跨度不足，阶段仅为
  描述性分组"。
- 阶段边界是分析工具，不是"领域范式转换"的证据；报告写"本批文献的阶段划分"，不写"该领域在
  2022 年发生转向"。

## 3. 主题演化

1. 主题由标题 + 关键结果句 + 高频词项的共词连通分量生成（共享 ≥2 个 `df≥2` 词项连边），
   不使用预设框架。
2. 每个主题记录 `support`、`count`、`year_span`（最小/最大年份）。
3. **新兴候选**：满足 `count≥2`、`last_year - first_year ≤ 2`，且 `last_year ≥ 语料最大年份-1`。
   报告只称"候选"，并列出首末年份与篇数；不把换词、缩写变体当成新主题。
4. **术语漂移**：同一主题内不同年份使用不同标签时，报告并列显示各阶段 `top_terms`，不做
   "合并为同一概念"的自动断言。

## 4. 各阶段代表作

选取规则（可复算，且不依赖被引数）：

```
排序键 = (是否有全文, 年份更早, 结果句数量) 降序
每阶段取前 2 篇
```

- 材料通常不提供被引数据，因此**明确不使用被引数**；若题面提供引用数，需在报告写明口径切换。
- 代表作只代表"该阶段本批材料中的信息量较大者"，不代表领域公认里程碑。
- 每篇代表作必须能在 `matrix.csv` 找到结果句或引文；找不到则降级为"仅题录"并注明。

## 5. 研究空白

只接受两类可核缺口：

1. **作者明说**：`future work / remains unclear / 尚未 / 有待 / 缺乏` 等句子，逐条给来源；
2. **证据稀薄**：主题仅 1 篇支撑，无法形成稳定结论。

以下**不得**写成空白：本批材料未出现某关键词、某年 0 篇、检索式未覆盖的数据库。报告第 6 节
固定声明"不能区分检索遗漏与真实空白"。

## 6. 冲突与不确定性

- 同一主题下结果方向相反（提高/有效 vs 无差异/不显著）时成对列出，保留年份与原文引文；
  脚本只提示方向不一致，判定需人工核对结局、人群与统计口径。
- 缺全文、缺摘要、缺年份分别统计；证据强度按 `high/medium/low` 标注，不把摘要级证据写成
  全文级结论。
- 年度表、阶段表、代表作表都可从 `matrix.csv` 复算；`verify` 会检查引文逐字命中与引用编号
  是否都在纳入集合内。

## 7. 适用边界

- 适合 5–200 篇、跨 ≥3 个年份的文献集；更小样本只做描述统计。
- 中文分词为二元组近似，英文按词；缩写与同义词需在题面词表中显式给出，否则可能分成不同主题。
- 不做外部检索与引文网络分析（材料未提供被引关系）；不替代人工判读图表与补充材料。
