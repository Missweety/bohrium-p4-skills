# 问答口径 · 文献智能问答

## 必须做

1. 逐题回答，覆盖每个问题及其全部子问；必要时整合方法、结果、讨论和表格中的信息
2. 为主要论断附对应论文标识、原文段落编号和短引文，使答案与证据一一核对
3. 准确保留数值、单位、比较对象、实验条件和结论范围，区分论文实测结果（reported）、作者解释与自己的推断（inferred）
4. 材料未报告时说明无法确定；只能部分回答时列出缺口；原文冲突时指出冲突及出处；读取失败时明确报告
5. answers[] 每个问题一项，含 question_id、answer、conditions，不得省略无法回答的问题
6. claims[] 每项含 claim_id、text、kind 与 evidence[]（每条证据含 paragraph_id 与 quote）
7. coverage 说明已读章节、未读章节及原因
8. status 明确区分 answered / partial / insufficient_evidence / input_error

## 禁止

- 任务仅依据给定材料作答，不联网检索、不做 PDF 解析/图像像素识别/补充附件读取
- 不能编造答案或引用
- 不得省略无法回答的问题
- 不得预置正式案例答案、伪造执行记录、读取隐藏评分数据或写入评分目录
- 完整覆盖与合理说明材料不足均可获分，不得仅凭状态标签或未回答列表判定漏答
- 不得因缺材料而伪造有依据的回答

## 状态词表

- 回答级：`answered`（完整回答）/ `partial`（部分回答）/ `insufficient_evidence`（材料不足）/ `input_error`（输入读取失败）
- 论断级：`reported`（原文报告）/ `inferred`（推断）

## 证据锚点

- `paragraph_id` —— 材料中的真实段落编号，原样保留，不自造
- `quote` —— 该段落的连续原文片段，逐字复制

## 本题独有能力

把每个答案拆成“论断—段落—短引文”三元可核验结构，并显式区分原文报告与推断、完整/部分/材料不足四态，控制数值与比较对象的条件不丢失。
