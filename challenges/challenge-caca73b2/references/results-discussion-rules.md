# 结果与讨论写作规则（可执行版）

每条规则都给出：判定口径 → 反例 → 改法。写完后用 `scripts/stat_claim_checker.py` 扫一遍，
再逐条人工确认；脚本只报位置，不做判断。

## R1 结果段只写观察，讨论段只做解释

- 结果段禁止出现：`推测`、`可能是因为`、`提示可能`、`we speculate`、`suggest that`、机制归因。
- 讨论段禁止引入结果段没出现的新数值；需要引用数字时回指（"如 3.2 节所述"）。
- 判定：`sectioning.numbers_only_in_discussion` 为空；`interpretation inside results` 告警为 0。

反例（结果段）：`处理组升高，说明该通路被激活。` → "说明…被激活"是解释。
改法：`处理组均值 15.1（SD 2.2，n = 10），对照组 12.4（SD 1.8，n = 11）`；解释移入讨论。

## R2 显著性三件套：n、统计量、p 值

出现 `显著 / significant` 的句子必须同时具备：

| 要素 | 允许写法 | 不允许 |
|-|-|-|
| 样本量 | `n = 10`、`每组 10 例` | 只写"多例" |
| 检验统计量 | `t = -2.31, df = 19` / `F(2,27) = 4.1` | 只写"经检验" |
| p 值 | `p = 0.032`、`p < 0.001`、`ns` | "显著"却无 p |

- 未达显著必须写清：`p = 0.08，未达显著`；不得写成"有升高趋势"再暗示结论。
- 多重比较：给出校正方法与校正后的 p（或 q），未校正就写明"未校正"。
- `显著性` 与 `效应量` 分开写：p 小不等于效应大。

反例：`两组差异显著。` → 缺 n/统计量/p。
改法：`两组差异显著（t = -2.31, df = 19, p = 0.032, n = 11 vs 10）`。

## R3 均值与误差必须声明口径

- `均值 ± 误差` 必须写明是 SD、SEM 还是 95% CI；图注与正文口径一致。
- 误差棒含义写进图注；多样本/多面板时说明误差是组内还是组间。
- 有效数字与仪器/统计输出一致（不把 12.43 写成 12.4 之外的位数）。

反例：`12.4 ± 1.8`（未说是 SD 还是 SEM，差 √n 倍会让读者误判离散度）。

## R4 相关 ≠ 预测 ≠ 因果

- 观察性数据只能写 `与…相关 / associated with`；出现 `导致/引起/cause/leads to` 时必须有干预或
  随机化证据，否则改为相关表述并把机制解释标为"推测"。
- 预测性结论写清预测对象与验证集；不得用训练集内表现支撑"可预测"。
- 机制句必须带限定：`可能通过…`，并在讨论中说明替代解释。

反例：`高剂量组炎症因子升高，因此药物导致了炎症。` → 无干预对照。
改法：`高剂量组炎症因子高于对照组（…），二者相关；是否存在因果需干预实验验证。`

## R5 讨论中的每个论断要落到"本研究数据"或"具体文献"

- 三类句子分开写：`本研究观察到…`（引本文章节/图表）、`既往研究报道…[n]`（必须带引用）、
  `我们推测…`（明确标推测）。
- 一致/不一致都要写：`与 X 等 [3] 一致`、`与 Y 等 [4] 报道的方向相反，可能原因是…`。
- 只堆引用不讲关系（"已有大量研究 [1-9]"）视为未完成。

判定：`literature` 列表为空（无未带引用的文献性陈述）。

## R6 局限必须落在具体层面

合格局限至少命中两个层面，并说明影响哪条结论：

| 层面 | 合格写法 | 空话 |
|-|-|-|
| 样本 | "单中心、n = 21，无法排除选择偏倚" | "样本量有限" |
| 测量 | "仅测总浓度，未区分活性形式" | "测量存在误差" |
| 设计 | "横断面设计无法确定时序" | "设计不够完善" |
| 统计 | "未做多重比较校正，阳性结果可能膨胀" | "统计方法有限" |

- 展望不得写"未来将进一步深入研究"；要写"下一步需 A 实验验证 B 结论"。

## R7 图注自洽

- 图注必须能独立读懂：对象、n、误差含义、统计方法、显著性标记含义。
- 正文引用编号与图注编号一致；补充材料用 `Figure S1` / `图 S1`，与主图分开编号。
- 多面板图写清 A/B/C 各是什么，不能只写"如图所示"。

## R8 阴性结果与不一致证据

- 阴性结果照写，并给出 n 与检验；不得隐去。
- 与假设不符的结果要进讨论，说明可能原因（测量、剂量、人群），不得只留支持性证据。
