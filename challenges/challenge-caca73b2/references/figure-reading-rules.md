# 图表读数与转写规则

目标：正文里的每个数值都能回指"哪张图/哪张表/哪份统计输出"，且单位、有效数字、误差含义不走样。

## 1. 读数优先级

1. 原始数据表（csv/xlsx）> 2. 统计输出（含检验名、df、p）> 3. 图注中明确写出的数值 > 4. 图形目测。

- 只有图形时：只写"目测不可精确读取"的量级描述，或标 `[MISSING: exact value]`，不得给出精确小数。
- 图与表冲突：两值都记，标 `CONFLICT`，正文用保守表述并进 `uncertainty`。

## 2. 单位与量纲

- 单位随数值出现，不写在句末统一说明（避免跨句歧义）。
- 换算必须显式：`12.4%（即 0.124）`；不得静默换算。
- 浓度/剂量写清分母（`mg/kg` vs `mg/mL`）；时间写清 `min` / `h`。

## 3. 误差与离散度

| 图中形态 | 正文必须写 | 禁止 |
|-|-|-|
| 误差棒 | `均值 ± SD`（或 SEM / 95% CI），并说明 n | 只写 `±` |
| 箱线图 | 中位数与四分位距，说明须/异常值定义 | 说成"均值±SD" |
| 散点 + 拟合线 | 拟合类型、R² 或斜率、n | 只说"呈线性" |

## 4. 有效数字

- 与源输出保持一致；百分比保留 1 位小数时，全文统一。
- p 值：`p < 0.001` 不写 `p = 0.000`；`p = 0.032` 不写成 `p = 0.03`（除非全文统一位数并声明）。
- 不在正文重算统计量（如用均值和 SD 反推 t），只转写源输出。

## 5. 多面板与编号

- 面板：`图 2A`、`Fig. 2A`；正文首次引用按 1、2、3 顺序（脚本会检查首次引用序列）。
- 补充材料：`图 S1` / `Figure S1`，与主图独立编号，正文首次引用位置合理。
- 一图多组：图注列明每组 n 与处理条件。

## 6. 图注自洽检查

- [ ] 图注含：数据类型、n、误差含义、统计方法、显著性标记定义。
- [ ] 图注的组名与正文一致（不得正文"处理组"、图注"treated-2"）。
- [ ] 坐标轴单位与正文一致；对数轴写明 log 底数。
- [ ] 缩放/裁剪未改变相对关系；图像处理说明（如亮度调整）已声明。

## 7. 反例

- 反例 A：正文写 `抑制率 43.7%`，图上是 `~40%` 的柱高且无数据表 → 属于目测补数，应标 MISSING。
- 反例 B：图注写 `mean ± SEM, n = 3`，正文写 `mean ± SD` → 口径冲突，必须统一并以图注/统计输出为准。
- 反例 C：正文先引 `图 3` 再引 `图 1` → 首次引用顺序错，需重排或改编号。
- 反例 D：多面板图只写"如图所示，处理组更高" → 未指面板、未给 n、未给统计量。
